# OMNA v2 设计稿

在线画布（可点击操作）：https://claude.ai/artifact/3FhiBQHt491RLncHgtF66H ，看「后台形态」页。数据都是虚构人物「林屿」的模拟数据。

## 目录

- `screenshots/`：每张画板的截图（2 倍分辨率）。截图在没有 Noto 网络字体的环境里渲染，中文字形会和最终效果略有不同。
- `source/`：每张画板的源码（`.dc.html`）。它们依赖画布编辑器的运行时，**单独打开无法渲染**，只作为参考规格：布局、尺寸、颜色变量、字号、文案和交互逻辑都写在里面。
- `../PLAN.md` 文末附录说明了每张画板对应哪一节需求。

- 引导 2：「让 AI 工具帮你整理」放最前（推荐）。每个有说明文件的已连接工具一行：只读的先说明并请用户点「允许提议，开始整理」；然后给一句可复制的话，等待时实时显示「已收到 N 条」，3 分钟没收到给排障提示。「直接读取说明文件」（按结构拆分，类别可能要改）、从 ChatGPT 搬、拖入文件作为备选。
- 引导 3：按六个类别分组，每组可全选或全不选；每条标来源（某工具整理 / 按结构拆），类别做成可点的小标签，点开六选一；工具还在提交时顶部显示，新到的自动加进来；什么都没收到时给空状态。
- 连接新 Agent 时提示导入：主按钮改为「允许提议，让它整理」，复制那句话后建议一条条出现；收齐后可取消勾选、「记住 N 条」或「先放进待确认」；记住后可「撤销这次整理」。「直接读取文件（不用 AI）」降为次要入口。

## 实现时以什么为准

1. 行为和范围：以 `../PLAN.md` 为准。设计稿里出现、但 PLAN.md 列在「不做」或「延后」里的东西，不实现。
2. 视觉：以截图为准；具体数值（颜色、圆角、间距、字号）从 `source/` 里读。
3. 设计稿里的数字和文案（12 次、林屿、纸鸢等）都是示例，实际取自接口数据。

## 视觉规格速查

| 品牌绿浅底 | `rgba(46,118,86,.11)` | `rgba(108,196,155,.14)` |
| 提醒琥珀 | `#8A5A12`，浅底 `rgba(196,140,40,.13)` | `#E3B868` |

- 字体：`'Segoe UI Variable Text', 'Segoe UI', 'Noto Sans SC', system-ui`；终端示例用 `Cascadia Mono, Consolas`。
- 圆角：窗口和小窗 8 px；按钮和输入 5–6 px；标签胶囊 999 px。
- 字号：页面标题 26 px；记忆详情句子 18 px；列表句子 14 px；正文 13–13.5 px；辅助 12 px；快捷键 11 px。
- Agent 缩写色块（示例）：Claude Code `#A3532A`、OpenCode `#2B2B2A`、WorkBuddy `#3B6CA3`、Codex `#4B4F8C`。正式版请换成各客户端官方图标，并确认使用许可。
- 动效：只用于反馈；读取时托盘中心点「呼吸」1.6 秒；遵守系统的「减少动画」设置。
