# OMNA v2 设计稿

在线画布（可点击操作）：https://claude.ai/artifact/3FhiBQHt491RLncHgtF66H ，看「后台形态」页。数据都是虚构人物「林屿」的模拟数据。

## 目录

- `screenshots/`：每张画板的截图（2 倍分辨率）。截图在没有 Noto 网络字体的环境里渲染，中文字形会和最终效果略有不同。
- `source/`：每张画板的源码（`.dc.html`）。它们依赖画布编辑器的运行时，**单独打开无法渲染**，只作为参考规格：布局、尺寸、颜色变量、字号、文案和交互逻辑都写在里面。
- `../PLAN.md` 文末附录说明了每张画板对应哪一节需求。

## 2026-10-02 修订：说明文件交给 Agent 整理

拆分质量门没过（留出集类别正确率 36%），负责人决定整理说明文件首选交给已连接的 Agent。在线画布第 15 版改了三处，`source/` 已同步，**截图 `Onb2.png`、`Onb3.png`、`ConnectImport.png` 还是旧版**，以 `source/` 和在线画布为准：

- 引导 2：「让 AI 工具帮你整理」放最前（推荐）。每个有说明文件的已连接工具一行：只读的先说明并请用户点「允许提议，开始整理」；然后给一句可复制的话，等待时实时显示「已收到 N 条」，3 分钟没收到给排障提示。「直接读取说明文件」（按结构拆分，类别可能要改）、从 ChatGPT 搬、拖入文件作为备选。
- 引导 3：按六个类别分组，每组可全选或全不选；每条标来源（某工具整理 / 按结构拆），类别做成可点的小标签，点开六选一；工具还在提交时顶部显示，新到的自动加进来；什么都没收到时给空状态。
- 连接新 Agent 时提示导入：主按钮改为「允许提议，让它整理」，复制那句话后建议一条条出现；收齐后可取消勾选、「记住 N 条」或「先放进待确认」；记住后可「撤销这次整理」。「直接读取文件（不用 AI）」降为次要入口。

## 2026-10-03 修订（第 16 版）：引导精简为 3 屏

负责人要求引导少而快，第一次用不必要的都拿出引导。`source/` 已同步，`Onb4.dc.html` 已删除；**截图 `Onboarding.png`、`Onb2.png`、`Onb3.png`、`Onb4.png`、`ConnectImport.png` 都是旧版**，以 `source/` 和在线画布为准：

- 引导改为 3 屏：连接 → 带上你写过的说明（边收边勾）→ AI 眼中的你。原来的「批量确认」并进第 2 屏。
- 第 2 屏只有一条路：每份说明文件一张卡，交给第一个连上、会读这份文件的工具。「让它整理」一次点击同时允许提议并开始；之后同一张卡里给那句话，收到的建议直接带勾选框出现，底部「记住 N 条」。很像的不进列表，只说一句「留在待确认」。
- 从引导里拿掉：直接读取说明文件、从 ChatGPT 搬、拖入文件（都在「记忆」页「＋」或 Agent 页导入卡里）；改类别；很像的二选一；撤销这次导入。
- 那句话改为先让 Agent「查一下我的偏好」再整理：提交建议不会把连接标为已验证，读一次才会。
- 连接导入卡和「已写入配置」的提示合成一张，只剩三种状态：建议（「不用了」/「允许并开始」，「直接读取文件」收进 ⋯）→ 进行中（那句话 + 实时勾选列表 +「记住 N 条」）→ 完成（「已记住 N 条 · 撤销」）。点「不用了」或「停止」后只剩普通的验证提示。

品牌色是黑白（`brand/OMNA_Final_Guidelines.md`），绿色不是品牌色。引导、导入卡、主窗口、托盘小窗的主按钮、勾选和开关改用品牌黑，提示条、标签改成中性灰；绿色只留给运行状态。托盘图标和系统通知不变。

## 2026-10-03 修订（第 20 版）：标志统一为品牌标志

所有画板（标题栏、托盘小窗、通知、托盘图标）的标志从「圆环 + 中心点」换成 `brand/` 里的品牌标志（两侧镜像围着中心圆）。托盘五种状态：平时是完整标志；读取中中心圆变绿呼吸；有待确认右上一个绿点；暂停共享时中心圆空出；出问题时标志变淡加琥珀角标。`apps/desktop/src/tray-icons.cjs` 按同样规则绘制。截图 `Tray.png`、`Toast.png`、`Flyout.png`、`Window.png` 也是旧版。

## 实现时以什么为准

1. 行为和范围：以 `../PLAN.md` 为准。设计稿里出现、但 PLAN.md 列在「不做」或「延后」里的东西，不实现。
2. 视觉：以截图为准；具体数值（颜色、圆角、间距、字号）从 `source/` 里读。
3. 设计稿里的数字和文案（12 次、林屿、纸鸢等）都是示例，实际取自接口数据。

- 字体：`'Segoe UI Variable Text', 'Segoe UI', 'Noto Sans SC', system-ui`；终端示例用 `Cascadia Mono, Consolas`。
- 圆角：窗口和小窗 8 px；按钮和输入 5–6 px；标签胶囊 999 px。
- 字号：页面标题 26 px；记忆详情句子 18 px；列表句子 14 px；正文 13–13.5 px；辅助 12 px；快捷键 11 px。
- Agent 缩写色块（示例）：Claude Code `#A3532A`、OpenCode `#2B2B2A`、WorkBuddy `#3B6CA3`、Codex `#4B4F8C`。正式版请换成各客户端官方图标，并确认使用许可。
- 动效：只用于反馈；读取时托盘标志的中心圆「呼吸」1.6 秒；遵守系统的「减少动画」设置。
